# ИИ-Рекрутер

Учебный проект для сопоставления резюме с требованиями вакансии и подготовки текстов вакансий.

## Что работает сейчас

В веб-интерфейсе можно отправить контрольное резюме и критерии вакансии на сервер. Приложение показывает процент соответствия, статус по каждому критерию и цитаты из резюме. Сохранённый результат можно повторно открыть по ID.

Текущая версия работает на одном контрольном примере через учебный адаптер. Подключение ИИ для анализа произвольных резюме и генерация вакансий запланированы на следующие этапы.

## Структура проекта

- `frontend/` — веб-интерфейс на Flutter и Dart.
- `server/` — сервер на Python и FastAPI. Результаты сохраняются в SQLite.
- `tests/` — тесты сервера.

## Запуск демо

Для показа с командным сервером подключитесь к сети команды в Tailscale и убедитесь, что сервер запущен. Из корня репозитория выполните в PowerShell:

```powershell
cd frontend
flutter pub get
flutter run -d web-server --web-port=53144
```

Откройте `http://localhost:53144`. Оставьте предзаполненные данные и нажмите «Анализировать». Ожидаемый результат на контрольном примере — 60%. Чтобы открыть результат повторно, скопируйте полученный ID и воспользуйтесь кнопкой «Открыть сохранённый анализ».
